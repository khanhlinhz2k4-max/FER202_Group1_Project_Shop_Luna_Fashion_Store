2. CÁC BƯỚC BIÊN DỊCH TRÊN OVERLEAF:
--------------------------------------------------------------------------------
Bước 1: Truy cập https://www.overleaf.com và đăng nhập.
Bước 2: Bấm nút "New Project" -> Chọn "Blank Project" -> Đặt tên: "FER202_Group1_Final_Report".
Bước 3: Mở file `docs/LaTeX_Source/main.tex` trong project, Copy toàn bộ nội dung (Ctrl+A, Ctrl+C) và Paste đè vào file `main.tex` trên Overleaf (hoặc bấm biểu tượng Upload và tải file `main.tex` lên).
Bước 4: Kiểm tra Menu góc trên bên trái của Overleaf:
        - Compiler: pdfLaTeX (mặc định) hoặc XeLaTeX.
        - TeX Live version: 2024 hoặc mới nhất.
Bước 5: Bấm nút "Recompile" (màu xanh lá). Overleaf sẽ biên dịch toàn bộ tài liệu thành file PDF dài ~100 trang cực kỳ đẹp mắt và chuyên nghiệp.
Bước 6: Bấm biểu tượng "Download PDF" để tải file về máy và nộp bài!
