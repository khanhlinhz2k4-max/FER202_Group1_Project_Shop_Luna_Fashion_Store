================================================================================
   HƯỚNG DẪN XUẤT FILE PDF TỪ LATEX TRÊN OVERLEAF (CHỈ MẤT 1 PHÚT)
================================================================================

Bước 1: Truy cập trang web https://www.overleaf.com và đăng nhập (bằng Google).
Bước 2: Bấm nút "New Project" -> Chọn "Blank Project" -> Đặt tên: FER202_Group1_Report.
Bước 3: Copy toàn bộ nội dung trong file `main.tex` (nằm cùng thư mục này) dán đè vào file `main.tex` trên Overleaf (hoặc bấm nút Upload -> chọn file `main.tex`).
Bước 4: Sửa lại Họ tên & MSSV của 6 thành viên ở bảng trang bìa (dòng 82 - 95).
Bước 5: Bấm nút "Recompile" (màu xanh lá) -> Bấm nút "Download PDF" ở góc phải trên.
Bước 6: Đổi tên file PDF vừa tải về thành `FER202_Group1_Report.pdf` và bỏ vào file ZIP nộp bài!
================================================================================
